# 红色记忆数字展馆 · AI 红色教育沉浸式展厅

一个面向在校学生的红色文化科普单文件 Web 应用（hash 路由多视图）：以长征为主线，串联建党、建军、井冈山、延安、抗美援朝等时期的红色事件、故事、词条与名言，并接入大模型提供 **AI 问答、AI 出题解析、AI 语音讲解** 三类核心智能能力。

## 一、内容规模（数据内联在页面 JS 中）

| 数据集 | 数量 | 说明 |
| --- | --- | --- |
| 历史事件节点 NODES | 15 | 时间、地点、标题、简介、详述、关联故事、情境反思题 |
| 红色故事 STORIES | 17 | 标题、时间、地点、标签、导语、正文、历史背景、精神启示、演示视频 |
| 词条 TERMS | 14 | 名词与释义 |
| 名言 QUOTES | 7 | 语录与作者 |
| 内置题库 QUIZ | 15 | 单项选择题（题干、四选项、答案、解析） |

页面采用 hash 路由分视图浏览：首页（三维展厅 + 概览脉络 + 交互地图 + 时间轴 + 栏目入口卡片墙），点击顶部导航或首页卡片进入红色故事、精神传承、词条名言、反思问答、综合测验等独立视图，各栏目可一键返回首页；故事与事件详情以弹窗呈现，AI 助手为右侧抽屉。

## 二、技术栈

- 原生 HTML + CSS + JavaScript（IIFE 包裹），无框架、无构建工具，单文件即可打开。
- three.js r128（CDN，jsDelivr）做三维展厅；墙面（暗红绒布底 + 暗金五角星压纹）与地面（格纹 + 圆点暗花）均为程序化 Canvas 纹理；展板图片与标题纹理统一线性过滤、关闭非幂纹理 mipmap 以减少斜视闪烁；WebGL 不可用时自动降级为 2D 视图。
- 前端本地 RAG（双路混合检索）：关键词路——历史事件 / 人物 / 主题别名归一词典 + 查询扩展，字符 bigram 重合 + 标题加权 + 年份数字加权 + 查询覆盖率与类型权重重排序；语义路——调用 embedding 向量接口生成查询与资料片段向量，余弦相似度召回；两路得分加权融合（关键词 0.55、语义 0.45）取 Top-K。资料片段向量按 ref 缓存到 localStorage，避免重复计算；embedding 未配置、请求失败或超时时，语义路自动静默降级为纯关键词检索，对话不阻塞、不报错。
- 大模型接口：OpenAI 兼容 Chat Completions，支持流式（SSE）与非流式两种返回；支持 Function Calling，模型可自主调度展馆工具；对话保留最近多轮上下文。
- 语音能力：浏览器原生 Web Speech API——本地 TTS 合成朗读（speechSynthesis）与中文 ASR 语音提问（SpeechRecognition），均在浏览器端完成，不消耗模型额度。
- 事件地图：公开省级边界 GeoJSON 经等距圆柱投影简化为内联 SVG 轮廓，15 个事件按真实经纬度落位；大地色分层填色区分省域；路线按史实脉络分组连线（长征主线、建党建军星火线、会师—圣地线），跨时期史位点不强行相连，点击节点打开展板与信息侧栏，离线可用、不依赖地图瓦片服务。

### 架构分层

作品按职责分为六层，前端单文件内完成视图、数据、检索与调度，模型调用经可选代理转发：

```
浏览器页面
 ├─ 视图层：hash 路由多视图；three.js r128 三维展厅（不可用时降级 2D）；SVG 事件地图；卡片墙 / 弹窗 / 抽屉
 ├─ 数据层：内联 JS 数据集（事件 / 故事 / 词条 / 名言 / 题库）；场景图以 base64 字典内联
 ├─ RAG 检索层：关键词路（别名词典归一 + bigram 重合 + 覆盖率 / 类型加权）＋ 语义路（embedding 余弦相似度），0.55 / 0.45 融合；向量片段缓存于 localStorage
 ├─ Agent 调度层：Function Calling 工具集（检索资料 / 查词条 / 出练习题 / 朗读 / 打开展板），最多 3 轮循环，保留最近 6 条上下文
 └─ 模型接入层：OpenAI 兼容 Chat Completions，支持 SSE 流式与非流式；接口失败自动回退本地检索 / 本地题库
        │  HTTPS 或 localhost
        ▼
   llm-proxy.js（可选代理：注入真实 Key、回写 CORS、分流 chat / embeddings，支持 .env）
        │  Bearer Key（仅后端持有，前端不接触）
        ▼
   厂商大模型端点（智谱 GLM / DeepSeek 等 OpenAI 兼容服务）
```

## 三、AI 核心功能

1. **红色故事 AI 问答助手**（右侧抽屉，导航「AI 助手」或右下角悬浮球进入）
   - 先在本地知识库（事件 / 故事 / 词条 / 名言）中检索相关片段，把片段作为上下文交给大模型作答；回答下方标注「资料来源」。
   - **Agent 工具调度（Function Calling）**：模型可根据问题自主调用展馆工具——`search_knowledge` 检索资料、`get_term` 查询词条、`generate_quiz` 生成练习题、`speak_text` 语音朗读、`open_event` 打开展板；前端执行工具后把结果回传模型，由模型总结作答，最多循环 3 轮。
   - **多轮上下文记忆**：保留最近 6 条对话（user / assistant 文本），支持追问与指代理解；工具中间消息不入历史，每轮资料按当前问题重新检索。
   - **语音提问（ASR）**：点击麦克风用中文语音提问，识别文本自动填入并发送；浏览器不支持语音识别时自动隐藏麦克风，回退文字输入。
   - 系统提示词约束：展馆资料优先作答；资料未覆盖的通用知识可补充并标注「（资料外补充）」；红色史实不编造、立场正面规范、表述通俗；对歪曲历史、否定革命、抹黑英烈等错误言论不附和，依据正确史实纠正并引导尊重先烈；对违规违法、暴力、隐私等不当请求简短拒答并引导回红色话题；无关常识简要回应并引导回红色主题。
   - 未配置接口、模型不支持工具调用或调用失败时，自动回退到本地检索答案并附来源，页面始终可用。

2. **AI 智能出题 + 解析**
   - 场景弹窗：针对当前事件生成专项练习。
   - 故事弹窗：针对当前故事生成专项练习。
   - 综合测验区：基于全馆资料生成综合专项练习。
   - 大模型按约定 JSON 数组输出单选题（题干、四选项、正确下标、解析）；前端做格式校验与容错解析。解析失败 / 未配置接口时，回退到本地题库按主题匹配组卷。

3. **AI 语音讲解**
   - 事件场景、红色故事均可一键朗读（事件讲时间地点与详述；故事讲导语、正文、背景与启示）。
   - 可再次点击停止；切换 / 关闭弹窗时自动停止朗读。

### AI 安全与可控

- **资料优先与来源溯源**：作答先检索展馆资料片段，回答下方标注「资料来源」（事件 / 故事 / 词条 / 名言）；资料外的通用补充必须标注「（资料外补充）」，与展馆资料区分。
- **史实与立场约束**：系统提示词要求立场正面、表述规范，不娱乐化、不戏说，不编造未经核实的数字、人名、番号；对歪曲历史、否定革命、抹黑英烈的错误言论不附和，依据正确史实纠正并引导尊重先烈。
- **越界内容拒答**：对违规违法、暴力、隐私或其他不当请求，简短说明无法提供并引导回红色历史话题；无关常识简要回应。
- **输出兜底**：模型返回空 / 纯空白文本、工具调用失败或接口异常时，自动回退本地资料检索答案并附来源；未配置接口时整体运行本地兜底模式，页面始终可用。
- **Key 隔离**：真实 API Key 只存在本机浏览器 localStorage、被 `.gitignore` 忽略的 `config.local.js` 或后端代理环境变量中；页面源码、配置模板与公开仓库均不写入真实 Key；走代理时前端只持有占位串，由后端注入真实 Key。

## 四、大模型配置（API Key 不写入仓库与页面源码）

配置读取优先级：外置 `window.__AI_CONFIG__` → 浏览器本机 localStorage → 空默认（本地资料模式）。

### 方式 A：页面内填写（最简单，Key 仅存本机浏览器）
点击 AI 抽屉右上角「接口设置」，选择预设或自定义端点，填入 Key 后保存到本机 localStorage；源码与公开仓库中不出现任何真实 Key。

### 方式 B：外置配置文件（不入库）
1. 复制 `config.example.js` 为 `config.local.js`；
2. 在 `config.local.js` 中填入 `apiBase / apiKey / model`；可选 `embeddingBase / embeddingModel` 指定向量接口与模型（不填时按聊天端点自动推导；不支持向量接口的厂商自动禁用语义路）；
3. 该文件已在 `.gitignore` 中，不会提交到 Git 仓库。

### 方式 C：本地 / 后端代理（智谱等不支持浏览器跨域的端点必走）

实测：智谱 GLM 端点不返回浏览器跨域放行头，纯前端直连会被 CORS 拦截；DeepSeek 端点允许浏览器跨域直连。使用零依赖代理脚本 `llm-proxy.js` 转发，真实 Key 只存在后端环境变量，前端不接触 Key。

1. 在本目录启动代理（PowerShell）：
   ```powershell
   $env:LLM_API_KEY="你的大模型 Key"
   node llm-proxy.js
   ```
   可选环境变量：`PORT`（默认 8787）、`LLM_UPSTREAM`（上游聊天端点，默认智谱）、`EMBED_UPSTREAM`（上游向量端点，默认智谱 embeddings）、`LLM_MODEL`（强制覆盖模型名）。代理按请求路径分流：`/chat/completions` 走聊天端点，`/embeddings` 走向量端点，均由后端注入同一 Key。
2. 在页面 AI 抽屉「接口设置」中填写：
   - 接口地址：`http://localhost:8787/chat/completions`
   - 模型名：`glm-4.7-flash`
   - API Key：任意非空占位串（如 `local-proxy`），真实 Key 由代理注入。
3. 公网部署时把代理托管到服务器，`LLM_API_KEY` 配为服务器环境变量，前端 `apiBase` 指向线上代理地址。

### 预设端点（OpenAI 兼容）

| 提供方 | apiBase | model |
| --- | --- | --- |
| 智谱 GLM（免费额度） | `https://open.bigmodel.cn/api/paas/v4/chat/completions` | `glm-4.7-flash` |
| 智谱 GLM（轻量备选，需账户额度） | 同上 | `glm-4.5-airx` / `glm-4.5-air` |
| DeepSeek | `https://api.deepseek.com/chat/completions` | `deepseek-chat` |
| 自建代理 / 其他兼容服务 | 自定义 | 按后端配置填写 |

> 免费模型 `glm-4.7-flash` 在高峰时段可能返回 429（访问量过大）；如持续限流，可把模型名改为 `glm-4.5-airx`（轻量极速，消耗账户额度），问答与出题会自动回退到本地题库/资料检索作为兜底。

## 五、安装与运行指南

### 环境要求

- 浏览器：Chrome / Edge 现代版本；
- 本地代理（仅智谱等需代理的端点）：Node.js 16 或更高版本；
- 无需前端构建工具，项目没有 npm 运行时依赖，不需要 `npm install`。

### 直接浏览（不接模型也能用）

1. 确保 `长征精神数字展馆.html` 与 `assets/` 文件夹位于同一目录；
2. 用现代浏览器打开 HTML 文件即可；固定内容离线可看，三维展厅库走 CDN，需联网加载，离线时自动降级 2D 视图；
3. 不配置大模型时，问答、出题、语音均以本地兜底模式运行。

### 接入大模型

三种接入方式见「四、大模型配置」。本地代理二选一启动：

```powershell
# 方式一：命令行注入环境变量
$env:LLM_API_KEY="你的大模型 Key"
node llm-proxy.js

# 方式二：使用 .env（复制 .env.example 为 .env 并填入 Key，脚本启动时自动读取）
node llm-proxy.js

# 或通过 npm 脚本（不安装依赖）
npm run start-proxy
```

### 环境变量（代理侧）

| 变量 | 作用 | 默认值 |
| --- | --- | --- |
| `PORT` | 代理监听端口 | `8787` |
| `LLM_API_KEY` | 真实大模型 Key，仅后端持有 | 空（未配置时代理返回 500） |
| `LLM_UPSTREAM` | 上游聊天端点（OpenAI 兼容 chat/completions） | 智谱 GLM 聊天端点 |

环境变量模板见 `.env.example`；`.env` 与 `config.local.js` 均已被 `.gitignore` 忽略，禁止提交真实 Key。

## 七、已知限制

- RAG 为前端轻量双路检索：关键词路（别名词典归一 + bigram 重合 + 覆盖率/类型加权）与语义路（embedding 向量余弦相似度）融合排序；未配置或不支持向量接口的厂商仅走关键词路。片段向量缓存在本机 localStorage，更换资料后需清一次缓存键 `cz_rag_vec_v1`。弱相关片段仍可能进入 Top-K，最终作答范围由系统提示词与资料来源标注约束。
- Function Calling 依赖所选模型支持工具调用；模型不返回 `tool_calls` 时自动回退为纯文本对话，展馆工具改由界面按钮手动触发。
- 语音合成音色与语音识别可用性取决于浏览器（推荐 Chrome / Edge）与本地语音包/网络；不支持 ASR 的浏览器会隐藏麦克风，回退文字输入，TTS 表现也可能因设备不同。
- 演示视频使用公开 B 站嵌入链接，个别视频可能因原作者设置而无法播放。
- 大模型接口跨域（CORS）由提供方决定：实测智谱 GLM 不允许浏览器直连，须走 `llm-proxy.js` 代理；DeepSeek 允许浏览器跨域直连。公网部署建议统一走后端代理。
